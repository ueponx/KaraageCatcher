# からあげキャッチゲーム 🍗

鳥居の中から投げられる からあげ をキャッチする、シンプルな2Dアクションゲーム。

## 🎮 ゲーム概要

制限時間60秒以内にできるだけ多くの唐揚げをキャッチしてハイスコアを目指すゲームです。

### 特徴

- ⏱️ 60秒間の短時間プレイ
- 🎯 コンボシステムで高得点を狙える
- 🏆 ハイスコア自動保存
- 🎵 レトロ風BGMと効果音
- 🎨 HTML5 Canvas描画

## 🕹️ 遊び方

### 操作方法

| キー | 動作 |
|------|------|
| `←` `→` または `A` `D` | 左右移動 |
| `スペース` | ジャンプ |

### ルール

- **唐揚げ（🍗）**: キャッチすると+1点（コンボで倍率UP）
- **レモン（🍋）**: 当たると2秒間スタン
- **コンボ**: 1.5秒以内に連続キャッチで倍率上昇（最大x4）

## 🚀 実行方法

### 方法1: ブラウザで直接開く

1. `karaage-catch-game.html` をダブルクリック
2. ブラウザで自動的に開きます

### 方法2: ローカルサーバーで実行（推奨）

```bash
# Python 3の場合
python -m http.server 8000

# Node.jsの場合
npx http-server
```

ブラウザで `http://localhost:8000/karaage-catch-game.html` を開く

## 📋 システム要件

- **ブラウザ**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **画面解像度**: 最小 800x600px
